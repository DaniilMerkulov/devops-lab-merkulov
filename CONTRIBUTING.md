# Правила участия в проекте

Спасибо за интерес к проекту! Чтобы внести изменения, следуйте этим правилам.

## Как вносить изменения
1. Создайте отдельную ветку от `develop` для своей задачи (например, `feature/название-задачи`).
2. Вносите изменения небольшими логичными коммитами.
3. Пишите понятные сообщения коммитов на английском или русском языке, кратко описывающие суть изменения.
4. После завершения работы создайте Pull Request в ветку `develop`.

## Стиль кода и оформления
- Используйте понятные имена файлов и переменных.
- Комментируйте сложные участки кода.

## Ветки
- `main` — стабильная версия проекта.
- `develop` — ветка для активной разработки.
- `feature/*` — ветки для отдельных задач.
